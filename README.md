# OSINT Investigation Toolkit (Debian-Based)

A Debian-based OSINT toolkit designed for digital investigations, reconnaissance, and open-source intelligence gathering.  
This project provides a structured and reproducible OSINT environment using well-known open-source tools.

⚠️ **This project does NOT include a virtual machine image.**  
It provides scripts and documentation to recreate the OSINT setup.

---

## 🛠 Tools Included

The following open-source tools are used in this OSINT machine:

- **ExifTool** – Metadata extraction from images, documents, and media files  
- **Maigret** – Username search across multiple social networks  
- **Sublist3r** – Subdomain enumeration tool  
- **URLHunter** – URL and endpoint discovery tool  
- **InstaLooter** – Instagram media downloader (public data only)  
- **Sherlock** – Username enumeration across social platforms  
- **theHarvester** – Email, domain, and subdomain intelligence gathering  

---

## 📦 Installation

Clone the repository and run the installation script:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
chmod +x install.sh
./install.sh

🚀 Usage

Run individual tools manually or through your automation script (if provided).

Example:

./osint.sh example.com

📁 Output Structure

Results generated by the OSINT tools are stored in:

osint_results/
└── target_name/
    ├── subdomains.txt
    ├── usernames.txt
    └── metadata.txt
